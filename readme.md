# PseudoScript
This is an experimental language made using Python. It will be called: PseudoScript! I hope to make this languge accessible and legible for everyone, so everyone knows exactly what your code does!

If it helps, I will explain the code as the language evolves in this very file.

Syntax Examples:

` variable a 10 ` 
This is a reassignable variable. Store anything!

` constant b 10 + 2 ` 
This is a non-changing variable. Store it once, and the value will never change.

` log(20 // 2) ` 
A printing statement that outputs something to your terminal.

` function divide(a, b)
    return a / b ` 
Soon, but you get the gist.
